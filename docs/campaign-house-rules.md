# Campaign House Rules

## Status

Status: Active campaign decisions

These rules override the official SRD only where an override is stated
explicitly.

Precedence for mechanics:

1. Explicit house rule in this document
2. Official Daggerheart SRD
3. Optional private Core Rulebook for examples or additional guidance

A missing entry is not a house rule.

## Fear

No house-rule change is currently recorded. The confirmed application range is:

- The campaign Fear pool has a minimum of 0 and a maximum of 12.
- Adjustments that would move Fear outside this range are not permitted.

This resolves the application's global Fear bounds. It does not define any
automatic extended-downtime behavior, which remains a separate workflow.

## Resting and downtime

House rule:

- Each character has a unique rest mechanic tied to their narritive, this option is executed via using the "Work on a Project" option for Long Rests.


## Inventory

House rule:

- Weight is ignored.
- Capacity is represented through inventory slots.

Open detail:

- Slot limits, item sizes, stacking, containers, and overloaded behavior are not
  yet defined.
- Do not enforce a capacity limit until those rules are recorded.

## Food

House rules:

- Each participating character consumes one ration per campaign week.
- Each ration has 7 portions, one for each day
- Fresh food spoils after two campaign weeks.
- Preserved food does not spoil through the normal weekly spoilage process.


## Death

No house-rule change is currently recorded.

## Witherwild campaign mechanics

No override to the official Witherwild corruption mechanic is currently
recorded.

The application may track Wither tokens only after the workflow and required
character fields are documented in `game-interpretation.md` and a task file.

## Homebrew summary

The following campaign rules are homebrew:

- One additional downtime option (Joined with the "Work on a Project")
- Slot-based inventory with weight ignored
- One ration consumed per participating character per campaign week
- Fresh food spoils after two campaign weeks
- Preserved food does not spoil through normal weekly spoilage
