# Open Questions

## Process

This file holds unresolved rules and product decisions. Do not guess an answer
in code; record the question here and continue only with unaffected work.

When a question is resolved:

1. Record the decision in the authoritative document (usually
   `docs/game-interpretation.md` or the relevant task in `docs/tasks/`).
2. Move the item to the Resolved section with the date and the decision.
3. Update affected tasks and tests.

Do not preserve decisions only in chat history.

Priority labels: `BLOCKER`, `HIGH`, `MEDIUM`, `LOW`.

## Entry format

```markdown
### OQ-<AREA>-<number> — <short title>

Priority: <label>
Raised: <date>, <task or context>

Question:

<the question>

Blocks: <task, phase, or "nothing yet">
```

Mechanics: before any mechanic is designed, ask the user whether it is core
(every campaign) or frame-exclusive, and how it works. Record unanswered
mechanic questions here.
