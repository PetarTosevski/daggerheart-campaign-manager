# Witherwild Campaign Notes

## Identity

Campaign frame: **The Witherwild**

Official spelling: `Witherwild`

Repository working title: Witherwild Campaign Manager

The repository folder may retain an older `WITHERWILDS-CAMPAIGN` name, but
product copy and code identifiers should use `Witherwild` unless a migration
would create unnecessary disruption.

## Source

Primary reference:

- `reference/daggerheart-srd.pdf`
- SRD printed pp. 113–118: The Witherwild Campaign Frame

## Campaign emphasis

The application should emphasize:

- Wilderness travel
- Survival
- Resource management
- Weekly environmental change
- Long-term consequences
- Active projects and threats
- Witherwild corruption
- Settlement development in a later phase

## Weekly cycle

The official campaign frame uses week-long periods of day and night.

The application should eventually display:

- Current campaign week
- Current light cycle: day or night
- Time remaining until the next transition
- A history of week transitions

Still to confirm:

- Whether a real-world session ending advances campaign time
## Weekly cycle

The campaign begins in a **Day** week.

Campaign weeks alternate automatically:

Day Week
↓

Night Week
↓

Day Week
↓

Night Week
↓

...

Each campaign week contains seven narrative phases.

### Day Week

| Day | Phase |
|------|------------------|
| 1 | Dawn |
| 2 | Sunrise |
| 3 | Morning |
| 4 | Forenoon |
| 5 | Midday |
| 6 | Afternoon |
| 7 | Civil Twilight |

### Night Week

| Day | Phase |
|------|--------------------------|
| 1 | Nautical Twilight |
| 2 | Astronomical Twilight |
| 3 | Evening |
| 4 | Night |
| 5 | Midnight |
| 6 | Dead of Night |
| 7 | Pre-Dawn |

At the completion of Day 7 (Civil Twilight), the campaign advances to Night
Week Day 1 (Nautical Twilight).

At the completion of Night 7 (Pre-Dawn), the campaign advances to Day Week Day 1
(Dawn).

## Witherwild corruption

The campaign frame uses Wither tokens on individual characters.

Potential application support:

- Current Wither-token count per character
- Token-event history
- Prompt to make the Fear Die check
- Record whether a scar was gained
- Clear tokens at session end
- Preview the corresponding Fear gain
- Preserve scar history

This must be implemented only through an approved task with verified rule
references.

## Important tracked state

Current priorities:

- Campaign weeks

- Fear

- Food

Later priorities:

- Settlements
- Population

- Prosperity
- Morale
- Medicine
- Wood
- Stone

`Hope` is primarily a character resource and should not be treated as a generic
world resource without an explicit homebrew rule.

## Interface priorities

During live play, prioritize:

1. Current week and day/night cycle
2. Fear
3. Wither-token alerts
4. Active countdowns
5. Food status
6. Character summaries
7. Recent activity

Survival information takes priority over detailed combat tooling.
