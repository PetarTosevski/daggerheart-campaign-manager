# TASK-D8-A1: SRD adversary catalogue data

Status: Done. Plan: `.omc/plans/d8.yaml`, tracer A1 (wave 1, no dependencies). Analysis: `.omc/autopilot/d8-analysis.md` sections 1-2.
User answers used: Hope & Fear text verbatim from the book (Q1); Weredragon adversaries frame-exclusive (Q7).

## Goal
`src/lib/srd/adversaries.ts` holds all 267 adversaries (129 Core, 135 Hope & Fear, 3 Reign of the Weredragon) as typed, checked data,
generated by `scripts/srd/gen-adversaries.mjs`.

## What was built
- `scripts/srd/gen-adversaries.mjs` (Node, no dependency). Run locally:
  `node scripts/srd/gen-adversaries.mjs --core <core.txt> --hf <hopefear.txt> [--check]`. The two arguments are the books' text
  (one `===== PAGE <printed page> =====` line per page) extracted from `.reference-private/` with pdfjs-dist; neither the books nor
  their text are committed, and nothing in CI runs the script. The generated file is committed. `--check` prints the cross-checks
  only.
  - Core 129: the board's `ADV` (verbatim, and the only source with the digits of CB pp.224-225), patched: Zombie Legion range Melee
    (CB p.239), Swarm of Rats Horde (10/HP) (CB p.218), Electric Eels Horde (2/HP) (CB p.222), Minor Chaos Elemental "Magical
    Reflection" (CB p.214), Tiny Red Ooze motives "Blaze, camouflage" (CB p.216), Vault Guardian Turret "piston-driven" (CB p.233), and
    the countdown label split out of the 12 merged feature names (`On My Signal`, kind `reaction`, `countdown: "Countdown (5)"`).
    "Corruptor" keeps the board's spelling (book typo "Corrupter" in the block heading; the CB p.209 index says "Corruptor"). The 10
    chapter-4 build examples are not included. Pages come from the Core text.
  - Hope & Fear 135 (HF pp.62-97) and the Weredragon blocks (HF pp.142-143) parsed from the book text: blocks start at the all-caps
    name above a `Tier` line; art captions and running heads (all-caps lines) and footers dropped; private-use digits U+E540+n mapped
    to n; ligature splits ("fi rst", "refl ect") joined; line-end hyphens kept as compounds ("purple-scaled"); numbered moves inside a
    feature kept as `\n\n- ` items like the board's Battle Box. Two glyphs read from rendered HF p.93 (`BOOK_FIXES`): Ghastly Legion
    "Horde (10/HP)" and Fire Titan Warlord "Countdown (6)" (U+E53F stands for different digits in two fonts), and the extraction space
    in "Get ’em Off!" (HF p.63). The tier digits of HF pp.142-143 are missing from the text; they come from the board (rendered pages:
    Forlorne Lykona Tier 4 Solo, Weredrake Tier 1 Standard).
  - Forlorne Lykona: the book prints a framework (description, motives, HP 11, Stress 8, Experience, Relentless (4), Transform, Feed on
    Fear) plus a Dragon Form and a Faun Form block (Difficulty, Thresholds, ATK, own features). Each form is one entry, "Forlorne Lykona
    (Dragon Form)" (p.143) and "Forlorne Lykona (Faun Form)" (p.142), with the framework repeated first, `frameId:
    "reign-of-the-weredragon"`.
  - A countdown printed at the start of a feature's text ("Countdown (1d6). When ...") moves into `countdown`, the same as the Core
    names, so `text` never starts with it. `fearCost` is stored where the text says "Spend a Fear" / "spend N Fear".
- `src/lib/srd/types.ts`: `AdversaryType`, `ADVERSARY_TYPES`, `AdversaryFeatureKind`, `AdversaryFeature {name, kind, text,
  fearCost?, countdown?}`, `AdversaryDef {id, name, tier, type, hordePerHp?, description, motives, difficulty, thresholds {major,
  severe} (null for "None"), hp, stress (null for Spellbound Armor's "None"), attack {modifier, name, range, damage}, experiences,
  features, source, frameId?, page?}`. `attack.modifier` is a number, or the string "+2d4" for Outer Realms Abomination. Nothing was
  added to the `src/lib/srd` barrel.
- `src/lib/domain/adversaries/index.ts` (pure, data-free): `minionValue`, `hordeDamage` (ASCII minus), `relentlessValue` (number, `"X"`
  for the variable Hydra / Xero, null), `featureFearCost`, `parseDamage` ({dice, modifier, type, direct}), `maxDamage`,
  `adversariesFor(list, {hopeAndFear, frameId})`, `WEREDRAGON_FRAME_ID`. `adversariesFor` takes the list as an argument so a caller of
  the other helpers does not bundle the 426 KB data; pass `ADVERSARIES` from `src/lib/srd/adversaries.ts`.

- HF p.61: Evolution "can't be triggered more than once in a scene."; HF p.143: "A weredrake is what a PC or an NPC becomes after being
  transformed by Forlorne's “Breath Weapon.”"

## Notes for later tracers
- Core text uses straight apostrophes (board), H&F text curly ones (book); search should fold both (A2's catalogue does accent/case
  folding anyway).
- `relentlessValue` is `"X"` for Hydra (heads) and Xero the Castle Killer (PCs in the scene): A4 should ask the GM or warn without a
  number.
- `featureFearCost` also counts costs such as Ramp Up's "You must spend a Fear to spotlight" and Execute Them!'s "Spend a Fear per PC"
  as 1; amounts the GM chooses ("spend any number of Fear") give null.
